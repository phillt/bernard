# src/provenance.ts

- **src/provenance.ts** — Per-turn `ProvenanceStore` that collects cite-able sources (`web` / `rag` / `memory` / `file` / `tool-result` / `user`). Retrieval tools (`web_read`, `web_search`, `file_read_lines`, `memory.read`, `scratch.read`) auto-register entries; RAG hits are registered by `Agent.processInput`. The store lives on `AgentContext.provenance`, is cleared at the start of every turn, and is shared by reference with sub-agent / tool-wrapper contexts (the wrapper dispatch takes the parent `AgentContext` directly since #316, so sharing is structural) so retrieval inside a wrapper specialist shows up in the parent's viewer. Treated as **untrusted data** (OWASP LLM01): `<available_sources>` lives in the per-turn user-role context message, not the SYSTEM channel, and every label/preview/rawRef is XML-escaped before interpolation. Citations are **always on for the main agent**: `buildMainSystemPrompt` (`src/framework/agents/main.ts`) appends `CITATIONS_PROMPT` unconditionally — grounding factual claims in checked sources rather than guessing is a core requirement, so it deliberately does NOT consult `policyDecision.citations` (the `citationsPolicy` still exists and defaults on, issue #173, but the main agent no longer depends on it). The SYSTEM prompt instructs the model to attach `[^Sn]` markers to factual claims, to verify a checkable fact with a tool before asserting it, and to prefix `[unverified]` when no source matches. The check-don't-guess + cite mandate is reinforced up front in `BASE_SYSTEM_PROMPT`'s Decision Rules. Use the `cite` tool to inspect the store mid-turn. **Shift+Tab** in the REPL toggles a pinned `<sources>` overlay showing the citations resolved against the last response (falls back to all-available when nothing was cited). The only carve-out is the skip-inline-markers gate `REASONING_FAMILIES`, which keeps OpenAI/xAI reasoning-family models (whose systemSuffix forbids narrating markers) from being told to emit them.
