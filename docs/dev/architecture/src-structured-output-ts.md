# src/structured-output.ts

- **src/structured-output.ts** — `{status, result, error?, reasoning?}` JSON parser for tool-wrapper output. Optional fields use `nullableOptional`, which is `.nullish().transform(v => v ?? undefined)` — so `null` is **normalized away at the parse boundary**, not at each consumer (#341): a model shown a four-key template emits four keys and puts `null` in the one that doesn't apply, and `z.string().optional()` rejects `null` — which discarded 18 of 37 wrapper runs in one observed session, every one of them work that had already succeeded. Widening alone is not enough: `wrapWrapperResult` and two spread sites in `tool-wrapper-run.ts` test `!== undefined`, so a surviving `null` would leak into the reasoning log and the parent agent's JSON against a type declaring `error?: string`. Doing it in the schema means every consumer keeps its pre-existing check and nobody has to remember — normalizing per consumer answers "did we cover them all?" by hand, once per field. `parseStructuredOutput` is generic over the **schema** (`z.output<S>`) rather than over `T`, because `z.ZodType<T>` defaults its Input to `T` and would otherwise infer the pre-transform type and hand back the `null`s it just removed. `TaskResultSchema` and `CorrectionOutcomeSchema` carry the same treatment — the latter is reached _through_ `WrapperResultSchema`, so an `error: null` there silently blocked correction-example commits too. Tool **parameter** schemas are deliberately left alone, but not because they self-heal — `makeRepairHook` retries an `InvalidToolArgumentsError` exactly once, and a failed repair still kills the dispatch, so a parameter rejection is terminal too, one materially-sized billed re-send later. The real blocker is that `.transform` yields a `ZodEffects`, which changes what `zod-to-json-schema` emits for tool parameters: the AI SDK advertises the **input** schema, so every optional would start advertising `["string","null"]` to the provider. That needs a per-provider emission check before it can be applied uniformly.
