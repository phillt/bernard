# agent-builder — the specialist that builds applet-action agents (#426).

- **`agent-builder` — the specialist that builds applet-action agents (#426).** Distinct from `specialist-creator`, which is given a concrete tool or CLI and researches its flags; this one is given a described capability need and chooses a **role**. `targetTools: ['specialist', 'tool_wrapper_run']` and deliberately no `shell`/`web_*` — there is nothing to research. `kind: 'meta'` is load-bearing four times: `tool_wrapper_run` refuses a `persona`, `toolSurface: 'full'` is what makes `specialist` constructible, meta runs do not enqueue correction candidates (an external caller's failure must not teach a local specialist), and `withSlot` makes its nested validation acquire free. It copies `specialist-creator`'s create → validate → delete-on-failure loop rather than `correction-agent`'s propose-and-hand-back, because **you cannot validate a specialist without creating it** — `tool_wrapper_run` takes an id that must resolve.
  - **The name is two tokens because the matcher scores a ratio.** `identityHits / |id segments ∪ name tokens|`, so extra words _lower_ it. `agent-builder` / "Agent Builder" measures **1.0** on "build the agent behind this applet button", 0.54 on a weaker phrasing and 0 on unrelated input.
  - **The rule with no code behind it** is that `targetTools` must cover the action's `toolAllowlist`: `grantedToolNames` is an intersection, so an under-declared specialist yields an action with fewer tools than its manifest promises — possibly none — failing as a bad answer rather than an error. It is a hard rule in the prompt, a guideline and a `badExample`, and nothing enforces it.
  - **`bundled-manifest.test.ts` makes the two-edit rule an invariant.** A new bundled record reaches existing installs only if its filename is in `POST_V1_BUNDLED`; that was written down in three places and enforced in none. The test walks the FILES on disk to the constant — the direction the mistake is actually made in — rather than iterating the constant, which would make the assertion self-consistent with whatever it says. `V1_BUNDLED` had to be written down for it: the v1 set existed only as "whatever was in the directory that day".
