How It Works

Plan. Act. Verify.

Bernard uses a Planner → Actor → Critic pipeline for complex tasks. Every tool call is observable and controllable.

01 — Plan

Understands intent

Breaks your request into a numbered plan with success criteria before touching anything. You see every step.

02 — Act

Executes with tools

Calls shell, file, web, and MCP tools to carry out the plan. Parallel sub-agents tackle independent steps concurrently.

03 — Verify

Checks its own work

A Critic agent reviews the output against the success criteria. Fails loudly rather than returning a plausible-sounding wrong answer.

🔒

Safe by default

Dangerous shell commands, write operations, and external API calls require explicit approval. Use /agent-options to tune confirmation thresholds or set read-only mode to block all writes until you allow them.

Quick Start

Up and running in two minutes.

Install globally from npm, set an API key, and start the REPL.

# Install globally
$ npm install -g bernard-agent

# Store your API key
$ bernard add-key anthropic sk-ant-...

# Start the REPL
$ bernard

# Or specify a provider / model
$ bernard -p openai -m gpt-4o

# Switch provider mid-session
bernard> /provider
# Switch model mode for cost control
bernard> /agent-options
01

Install

One command with npm. Requires Node.js 20 or later.

02

Add an API key

Use bernard add-key or set ANTHROPIC_API_KEY / OPENAI_API_KEY / XAI_API_KEY in your environment or ~/.config/bernard/.env.

03

Run

Type bernard to open the interactive REPL. Use -p and -m flags to choose provider and model. Switch any time with /provider and /model.

04

Explore

Type /help inside the REPL for the full command list. Configure model lineups, MCP servers, routines, and more from there.

Examples

What Bernard actually does.

Prompts you type and what happens. Every tool call is visible in the terminal in real time.

bernard> what git branch am I on?
  ▶ shell: git branch --show-current
  You're on the main branch.
bernard> check disk usage and count TypeScript lines in parallel
  ▶ agent: "Check disk usage"
  ▶ agent: "Count TypeScript lines"
  [sub:1] ▶ shell: df -h /
  [sub:2] ▶ shell: find . -name "*.ts" | xargs wc -l
  Disk: 42G used of 256G (16%). Code: 2,847 lines across 23 files.
bernard> every morning at 8am, check the deploy pipeline and notify me if it's red
  ▶ cron_create: "deploy-monitor"
  Schedule: 0 8 * * * (daily at 08:00)
  ✓ Created — will run tomorrow morning. Sends a desktop notification on failure.
bernard> schedule a meeting with alice@example.com for next Tuesday afternoon
  ▶ gmail: search "alice@example.com"
  ▶ google_calendar: list_events (Tue)
  ▶ gmail: send_email
  ▶ google_calendar: create_event
  Sent invite to alice@example.com. Calendar block created: Tue 3–4 pm.
  requires: google-gmail MCP + google-calendar MCP
bernard> remember that this project uses pnpm
  ▶ memory: write "project-conventions"
  Got it — I'll use pnpm for this project from now on.
